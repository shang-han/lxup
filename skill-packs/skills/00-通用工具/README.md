# 00-通用工具（预装免费技能包）

龙虾优盘出厂预装的通用能力型技能包（免费、不锁）。不针对具体岗位，扩展纯对话做不到的真实文件处理与办公能力。

## 版本

- v2.1.0：技能精简为 45 个。删除 3 个模型本身已会的冗余技能（正则表达式生成 / 单位换算 / 财务计算）；重写 4 个薄弱技能（Excel 真实样式与公式单元格、PPT 多级版式与备注、图片PDF 接入 pymupdf 真渲染、词云接入 jieba 中文分词）；10 个边缘技能注入「模板库 + 质量关卡」（周报月报 / 会议纪要 / 写作润色 / 邮件起草 / 通知公告 / 新媒体文案 / 本地知识检索 / 论文速读 / 代码审查 / 日志排障）。
- v2.0.0：技能扩充到 48 个，SKILL.md 统一为「定义 / 适用场景 / 核心能力 / 边界 / 执行流程 / 输出格式 / 示例 / 注意事项」结构。

## 技能形态

- **脚本型（34 个）**：SKILL.md + 独立 Python 脚本（`scripts/`），由便携 Python 执行，依赖缺失时脚本提示安装命令，退出码约定 0 成功 / 1 参数或依赖错误 / 2 处理错误。
- **纯指令型（11 个）**：只含 SKILL.md 提示词流程，零依赖。

## 依赖说明

- 已有便携环境内置：pypdf、python-docx、matplotlib、pillow、numpy、yaml
- 需按需安装（脚本会提示命令）：openpyxl、python-pptx、markdown、wordcloud、jieba、pymupdf、qrcode
