# 二维码生成解析

## 定义
把文本/URL 生成 PNG 二维码;或读取二维码图片里的内容。

## 适用场景
- 链接/联系方式要印在物料上
- 生成会议/加群二维码
- 想知道某张二维码图里是什么(先提醒安全:未知二维码不要扫)

## 核心能力
- 生成:文本/URL → PNG,可调尺寸与容错
- 解析:图片 → 文本内容(需 pyzbar,缺失时脚本提示安装)

## 边界
- 不生成支付码、身份凭证类二维码
- 解析未知来源二维码前提醒用户风险,不主动执行
- 二维码内容超长(>1000 字符)时提示可能扫描困难

## 执行流程
脚本位于本技能目录 `scripts/qr_tool.py`,依赖 `qrcode`、`pillow`(生成);解析另需 `pyzbar`(缺失时脚本提示安装命令)。

- 生成:`python scripts/qr_tool.py create "https://example.com" -o 二维码.png --size 400`
- 解析:`python scripts/qr_tool.py read 二维码.png`

退出码:0 成功;1 参数/依赖错误;2 处理错误。

## 输出格式
生成:回报图片路径与尺寸;解析:直接输出内容文本。

## 示例
输入:「把公司官网生成一个二维码」
动作:create → 二维码.png
回报:「已生成 二维码.png(400×400)。」

## 注意事项
- 依赖缺失时按脚本提示执行 `pip install "qrcode[pil]"`,不要静默失败
