# 词云生成

## 定义
用 jieba 对中文文本做真实分词与词频统计,渲染成词云图片,词的大小代表出现频率。

## 适用场景
- 报告/PPT 配一张主题词云
- 长文本的主题速览
- 舆情、评论的词汇热点

## 核心能力
- jieba 精确模式中文分词(不再是近似切词)
- 内置 200+ 中文停用词;支持用户提供停用词文件(每行一个词)
- 自定义遮罩形状、输出尺寸
- 输出前 10 高频词清单

## 边界
- 词云用于展示与速览,不做严谨词频研究(分词粒度可调但非学术级)
- 文本过短(<100 字)时提示词云意义不大
- 文本中的数字、网址、邮箱默认剔除

## 执行流程
脚本位于本技能目录 `scripts/wordcloud_tool.py`,依赖 `wordcloud`、`jieba`、`matplotlib`(缺失时脚本提示安装命令)。

- 基本:`python scripts/wordcloud_tool.py create 文本.txt -o 词云.png`
- 带遮罩:`python scripts/wordcloud_tool.py create 文本.txt -o 词云.png --mask 形状.png --size 1200x800`
- 自定义停用词:`python scripts/wordcloud_tool.py create 文本.txt -o 词云.png --stopwords 停用词.txt`

退出码:0 成功;1 参数/依赖错误;2 处理错误。

## 输出格式
回报图片路径、词数量、前 10 高频词。

## 示例
输入:「把这份用户反馈生成词云」
动作:create → 词云.png
回报:「已生成 词云.png,共 320 个词。前 10:卡顿、闪退、登录、……」

## 注意事项
- 脚本自动寻找系统中文字体(微软雅黑等)
- 依赖缺失时按脚本提示安装(`pip install "wordcloud" "jieba"`),不要静默失败
