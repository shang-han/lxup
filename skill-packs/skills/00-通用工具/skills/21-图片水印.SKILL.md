# 图片水印

## 定义
给一张或一批图片添加文字水印,输出到新文件(不覆盖原图)。

## 适用场景
- 对外发图前加版权/署名
- 商务材料标注公司名
- 样图加水印防盗用

## 核心能力
- 文字水印:内容、位置(四角/居中)、字号、透明度
- 批量处理整个目录
- 输出到独立目录,原图不动

## 边界
- 只加文字水印,不做隐形水印与去水印(去水印有版权风险,明确拒绝)
- 不覆盖原文件,默认输出到 原图名_wm 或指定目录
- 中文字体自动适配

## 执行流程
脚本位于本技能目录 `scripts/watermark_tool.py`,依赖 `pillow>=9.0`(缺失时脚本提示安装命令)。

- 单张:`python scripts/watermark_tool.py add 图片.jpg -o 输出.jpg --text "仅供预览" --pos br --opacity 120`
- 批量:`python scripts/watermark_tool.py batch ./图片目录 --text "公司名" --pos center --outdir ./加印`

pos 取值:tl/tr/bl/br(四角)/center。退出码:0 成功;1 参数/依赖错误;2 处理错误。

## 输出格式
回报处理数量、输出目录、样例文件路径。

## 示例
输入:「把这批照片右下角都加上"张老师 摄"」
动作:batch --text "张老师 摄" --pos br
回报:「已为 32 张图片添加水印,输出到 ./加印。」

## 注意事项
- 依赖缺失时按脚本提示执行 `pip install "pillow>=9.0"`,不要静默失败
