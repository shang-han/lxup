# 压缩解压

## 定义
对文件/目录做 zip 或 tar 打包与解包,产出真实归档文件。

## 适用场景
- 打包资料发送/归档
- 解压下载的 zip/tar 文件
- 打包时排除无用文件(node_modules 等)

## 核心能力
- zip / tar.gz 打包目录或文件列表
- 解压 zip / tar / tar.gz
- --exclude 排除规则(如 node_modules, .git)

## 边界
- 不支持 rar/7z 解压(需第三方工具,遇到时明确说明)
- 压缩不加密;需要密码的场景说明本技能不支持
- 解压路径冲突时报错不覆盖

## 执行流程
脚本位于本技能目录 `scripts/archive_tool.py`(标准库,无额外依赖)。

- 打包:`python scripts/archive_tool.py zip ./目录 -o 归档.zip --exclude node_modules .git`
- 解压:`python scripts/archive_tool.py unzip 归档.zip -o ./解压目录`
- tar:`python scripts/archive_tool.py tar ./目录 -o 归档.tar.gz` / `untar 归档.tar.gz -o ./解压目录`

退出码:0 成功;1 参数错误;2 处理错误。

## 输出格式
回报输出路径、文件数、压缩前后大小与压缩比。

## 示例
输入:「把这个项目打包发我,别带 node_modules」
动作:zip --exclude node_modules
回报:「已打包 项目.zip,186MB(排除 node_modules 后),压缩比 42%。」

## 注意事项
- 打包大目录耗时,先报告文件数与预估大小
