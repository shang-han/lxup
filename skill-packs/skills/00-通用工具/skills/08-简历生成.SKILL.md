# 简历生成

## 定义
把用户提供的个人信息(联系方式、经历、教育、技能)按通用简历版式生成 .docx 文件。

## 适用场景
- 求职需要一份规范排版的简历文件
- 已有零散经历信息,需要整理成正式简历
- 多岗位投递需要快速调整版本

## 核心能力
- 基本信息:姓名/电话/邮箱/求职意向
- 工作经历:公司、职位、时间段、要点列表
- 教育经历、技能清单
- 中文字体自适应、一页为主的紧凑排版

## 边界
- 只按用户提供的信息排版,不虚构经历、不夸大数据
- 不提供求职建议与职业规划意见
- 信息不全时先生成占位版,并列出缺失项让用户补

## 执行流程
脚本位于本技能目录 `scripts/resume_tool.py`,依赖 `python-docx>=1.0`(缺失时脚本提示安装命令)。

- `python scripts/resume_tool.py create 简历.docx --data resume.json`

规格(JSON):
```json
{
  "name": "姓名", "phone": "手机号", "email": "邮箱", "target": "求职意向",
  "summary": "一句话简介",
  "experience": [{"company":"公司","title":"职位","period":"2023.01-2025.06","items":["要点一"]}],
  "education": [{"school":"学校","major":"专业","degree":"学历","period":"2019-2023"}],
  "skills": ["技能一","技能二"]
}
```

退出码:0 成功;1 参数/依赖错误;2 处理错误。

## 输出格式
回报文件路径、页数估算、缺失字段清单(若有)。

## 示例
输入:「帮我按这些信息生成一份简历」
动作:整理为 resume.json,运行 create
回报:「已生成 简历.docx。提示:未填求职意向,建议补充。」

## 注意事项
- 敏感信息(身份证号、银行卡)不进简历,如用户提供应提醒
- 依赖缺失时按脚本提示执行 `pip install "python-docx>=1.0"`,不要静默失败
