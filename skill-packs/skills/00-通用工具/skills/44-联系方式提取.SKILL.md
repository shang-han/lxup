# 联系方式提取

## 定义
从文本文件中提取所有手机号与邮箱地址,去重后输出 CSV。

## 适用场景
- 聊天记录/文档里零散的联系方式要整理成表
- 名单数据清洗
- 建立通讯录

## 核心能力
- 手机号(11 位,1 开头)、邮箱正则提取
- 自动去重,保留首次出现位置
- 输出 CSV(类型,内容,来源文件)

## 边界
- 只识别标准格式;座机、短号、带分机号的不在范围
- 提取结果用于合法用途;批量营销/骚扰用途明确拒绝
- 原文件不动

## 执行流程
脚本位于本技能目录 `scripts/contact_tool.py`(标准库,无额外依赖)。

- `python scripts/contact_tool.py extract 文本.txt -o 联系方式.csv`
- 批量:`python scripts/contact_tool.py extract ./目录 -o 联系方式.csv --recursive`

退出码:0 成功;1 参数错误;2 处理错误。

## 输出格式
回报提取数量(手机号 N、邮箱 M、去重后),CSV 前 3 行预览。

## 示例
输入:「把这堆聊天记录里的手机号都提出来」
动作:extract → 联系方式.csv
回报:「提取手机号 87 个(去重后 62)、邮箱 14 个,已保存 联系方式.csv。」

## 注意事项
- 提取后建议抽查若干条确认无漏
