# 统计报告生成

## 定义
对 CSV 数值列做描述性统计分析,输出 Markdown 报告 + 分布直方图,并给出客观结论句。

## 适用场景
- 业绩/运营数据复盘
- 一批数据要出统计结论
- 数据分布是否异常的初步判断

## 核心能力
- 计数、缺失值、均值、中位数、标准差、最大/最小、四分位数
- 每列直方图输出
- 报告含「数据特征」与「需要关注的点」(如极端值、缺失比例)

## 边界
- 只做描述统计,不做预测与因果推断
- 小样本(n<10)只给数值不给结论
- 结论用数据说话,不夸大显著性

## 执行流程
脚本位于本技能目录 `scripts/stats_tool.py`,依赖 `numpy`、`matplotlib`(缺失时脚本提示安装命令)。

- `python scripts/stats_tool.py analyze 数据.csv -o 报告.md --cols 金额,数量 --fig-dir ./图表`

退出码:0 成功;1 参数/依赖错误;2 处理错误。

## 输出格式
报告.md:每列一节(样本数/缺失/均值/中位数/标准差/四分位 + 直方图路径),末尾「需关注」清单。

## 示例
输入:「分析下这个月的订单金额」
动作:analyze --cols 金额
回报:报告.md + 直方图,指出「金额存在 3 笔极端大额订单,建议单独核查」。

## 注意事项
- 非数值列会被跳过并说明
- 依赖缺失时按脚本提示安装,不要静默失败
