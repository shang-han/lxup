# 语音转写

## 适用场景
用户有**音频文件**想变成文字:会议录音整理、访谈转写、给视频配字幕、语音备忘转文本。纯对话模型听不到声音,本技能调用离线语音识别模型真正完成转写,并可生成带时间轴的 SRT 字幕。

## 核心能力
- 音频转文字(离线,基于 faster-whisper,支持中文/英文等多语种,自动检测语言)
- 输出纯文稿,或带时间轴的 SRT 字幕文件
- WAV(PCM)零额外依赖加载;自动转 16kHz 单声道
- 静音/纯音乐自动识别并提示(不会硬编内容)
- VAD 过滤静音段,多种模型规格可选(tiny→large,精度/速度权衡)

## 脚本调用
脚本位于本技能目录 `scripts/audio_tool.py`,依赖 `faster-whisper>=1.0`(含 numpy):

- 转写打印:`python scripts/audio_tool.py transcribe 录音.wav`
- 转写存文件:`python scripts/audio_tool.py transcribe 录音.wav -o 文稿.txt`
- 带字幕:`python scripts/audio_tool.py transcribe 录音.wav --srt 字幕.srt --language zh`
- 选模型:`--model tiny|base|small|medium|large`(默认 small;越大越准越慢)

退出码:0 成功;1 参数/依赖错误;2 处理错误。

## 输出格式
- 文稿:逐段文字,每段一行
- SRT:标准字幕格式(序号 + 时间轴 `HH:MM:SS,mmm --> ...` + 文本)
- 进度信息(语言/置信度/时长/分段数)输出到 stderr,不混入文稿

## 示例
输入:「把这段会议录音转成文字,再给我一份字幕」
动作:`python scripts/audio_tool.py transcribe 会议.wav -o 会议.txt --srt 会议.srt --language zh`
回报:「已转写 会议.txt(识别中文,时长 12 分钟,86 段),字幕 会议.srt。」

## 注意事项
- 必须真实调用脚本,不能凭空"编"转写内容
- **模型需下载**:首次使用联网从 HuggingFace 下载并缓存(tiny≈39M/small≈244M);
  **国内网络需先设镜像** `HF_ENDPOINT=https://hf-mirror.com`;离线部署应预缓存模型
- WAV(PCM)直接支持;mp3/m4a 等需 faster-whisper 自带解码器,失败时建议先转 WAV
- 模型规格按需选:实时性优先用 tiny/base,准确度优先用 small 及以上
- 转写结果为语音识别产物,重要内容(如法律/医疗)需人工复核
- 依赖缺失时按脚本提示执行 `pip install "faster-whisper>=1.0"`
