# 写作润色改写

## 定义
在不改变原意的前提下,提升文本的准确性、流畅度和语气得体度。

## 适用场景
- 汇报、方案、邮件发出去前想再改改
- 文字啰嗦、重复、有错别字
- 需要切换语气(正式/口语/简洁/热情)

## 核心能力
- 错别字、病句、标点修正
- 冗余压缩与结构调整
- 语气切换:正式 / 口语 / 简洁 / 热情
- 附修改说明(改了什么、为什么)

## 边界
- 不改变事实和数据,不加用户没提供的信息
- 不冒充作者立场,只改文字
- 金额、时间、人名等关键信息原样保留并提示确认

## 执行流程
1. 确认改动范围与目标语气
2. 先改,再自查错别字与事实项
3. 默认输出「润色后全文 + 修改说明」;用户只要成稿时只出成稿

## 输出格式
润色后全文在前;「修改说明」分点列在后(原文片段 → 改后 → 理由)。

## 示例
输入:「帮我润色这封邮件,正式一点」
回报:成稿 + 3 条修改说明(称呼、冗余句压缩、两处用词)

## 注意事项
- 用户给的信息不足时先问用途和语气,不猜
