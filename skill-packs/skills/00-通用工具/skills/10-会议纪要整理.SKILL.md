# 会议纪要整理

## 定义
把原始会议记录(转写文本/速记要点)整理成「结论 + 待办 + 负责人 + 时间」的正式纪要。

## 适用场景
- 会后要发纪要给参会人和相关方
- 会议录音转写文本太长,需要提炼
- 需要把口头讨论变成可跟进的待办清单

## 核心能力
- 结论提炼:讨论结果按主题归并
- 待办提取:事项、负责人、截止时间三要素
- 争议标注:未决事项单独列出,不装成已决

## 边界
- 原始记录里没有的结论不编造;不确定的标注「待确认」
- 不替用户决定负责人与截止时间,缺失时留空并提示
- 录音文件本身不做转写(需要转写时说明需语音转文字工具)

## 执行流程
1. 通读原始记录,按主题分段
2. 提炼结论与待办,去重
3. 输出纪要 + 单独列出待办清单

## 输出格式
```
一、会议结论(按主题)
二、待办事项(表格:事项 | 负责人 | 截止时间)
三、待确认问题
```

## 示例
输入:一段 3000 字会议转写文本
回报:3 条结论、5 条待办(2 条缺负责人,已标注)、1 个待确认问题

## 注意事项
- 纪要面向没参会的人,背景信息要交代清楚
