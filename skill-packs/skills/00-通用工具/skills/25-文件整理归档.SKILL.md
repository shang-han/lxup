# 文件整理归档

## 定义
按规则(扩展名类型 / 修改日期)把散乱文件移动到分类子目录。

## 适用场景
- 下载目录堆了几百个文件
- 桌面文件长期不整理
- 资料按月份归档

## 核心能力
- 按类型归类:文档/图片/视频/压缩包/安装包/其他
- 按日期归类:YYYY-MM 月份目录
- --dry-run 预览移动计划;同名文件自动避免覆盖

## 边界
- 只移动文件,不删除任何文件
- 目录自身与隐藏文件默认不动(可 --include-dirs 打开)
- 归类规则固定为内置类型表,不做智能内容识别

## 执行流程
脚本位于本技能目录 `scripts/organize_tool.py`(标准库,无额外依赖)。

- 按类型:`python scripts/organize_tool.py organize ./下载 --by ext`
- 按日期:`python scripts/organize_tool.py organize ./资料 --by date`
- 预览:`python scripts/organize_tool.py organize ./下载 --by ext --dry-run`

退出码:0 成功;1 参数错误;2 处理错误。

## 输出格式
dry-run:各类别文件数与目标目录;执行:移动总数与分类统计。

## 示例
输入:「帮我把下载目录整理一下」
动作:dry-run 预览 → 用户确认 → organize --by ext
回报:「已归档 143 个文件:文档 52、图片 30、压缩包 18、安装包 12、其他 31。」

## 注意事项
- 先 dry-run 给用户看分类结果,确认后再移动
