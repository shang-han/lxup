# 本地知识检索

## 定义
在用户指定的本地目录内,先定位相关文件,再检索内容,输出「结论 + 文件路径 + 原文摘录」。

## 适用场景
- 资料多,记不清内容在哪个文件
- 需要从本地文档中找到依据
- 跨多个文件找同一主题的内容

## 核心能力
- 文件名/目录名关键字定位
- 内容检索(逐文件关键词匹配,支持 md/txt/docx 等文本文件)
- 输出带路径与摘录,方便用户溯源

## 边界
- 检索范围必须在用户给的目录内,不擅自全盘搜索
- PDF/图片型内容无法检索时说明,不假装查过
- 大目录先报告文件量,分轮检索

## 执行流程
1. 确认检索目录与关键词
2. 先文件名命中,再内容匹配
3. 输出:结论摘要 + 命中文件路径 + 每处摘录(带上下文)

## 输出格式
```
结论:<一句话>
命中文件:
- 路径(命中 N 处)
  - 摘录:……
```

## 示例
输入:「在 D:\资料 里找关于"报销流程"的内容」
回报:3 个文件命中,每处摘录 + 路径,并总结流程要点

## 注意事项
- 检索不到时如实说明已检索的范围,不编造结果
