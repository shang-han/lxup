# 邮件起草

## 定义
按用途起草结构完整、语气得体的邮件(主题、称呼、正文、落款),用户微调即可发送。

## 适用场景
- 商务沟通、询价、催款、致歉、感谢
- 求职投递与面试跟进
- 回复客户/同事邮件

## 核心能力
- 类型适配:商务正式 / 内部简短 / 求职 / 跟进提醒
- 结构:主题行 + 称呼 + 三段式正文 + 落款
- 中英文均可;英文用标准商务措辞

## 模板库
- 延期致歉:主题「关于【项目/订单】交付时间调整的说明」;正文:一句直接道歉 → 原因(一句,可占位)→ 新的时间与补救措施 → 感谢理解
- 催款提醒:主题「【项目/合同号】款项支付提醒」;正文:简短问候 → 依据(合同/发票号)→ 金额与期限 → 付款方式
- 求职投递:主题「应聘【岗位】-【姓名】-【亮点 4-6 字】」;正文:一句话自我介绍 → 与职位要求匹配的 2-3 点 → 简历附件说明 → 感谢
- 会议邀请:主题「会议邀请:【议题】·【日期】」;正文:会议目的 → 时间地点 → 议程 → 需准备的材料
- 英文框架:Subject / Hi [Name], → 一句背景 → 正文要点(分点)→ Best regards + 落款

## 质量关卡(输出前逐条自查)
1. 主题行 ≤ 15 字(英文 ≤ 8 词),且含核心信息(事项+对象或时间)
2. 用户未提供的信息一律【】占位,全篇占位数 ≤ 3
3. 称呼与收件人关系匹配(客户/同事/上级)
4. 承诺、金额、日期均未编造

## 边界
- 不用用户没提供的承诺与数据(报价、期限留空让用户填)
- 不代发邮件(本技能只出文本)
- 敏感/冲突场景(裁员、索赔)建议用户人工撰写,只给框架

## 执行流程
1. 确认收件人关系与邮件目的,套用对应模板
2. 起草主题行与正文,关键信息(数字、日期)用【】占位
3. 过质量关卡再输出

## 输出格式
主题行一行;正文分称呼/正文/落款;占位项用【】。

## 示例
输入:「给客户写封邮件,说明交付延期一周并道歉」
回报:主题 + 致歉正文(延期原因占位,请用户补充),落款留空

## 注意事项
- 用户没说明收件人称呼时用通用称谓并提示替换
