# 文本差异对比

## 定义
逐行对比两个文本文件,输出统一 diff 文本或可视化 HTML 差异页。

## 适用场景
- 合同/文档改了什么要核对
- 代码版本对比
- 配置文件差异检查

## 核心能力
- 统一 diff(带 +/- 与行号)
- HTML 高亮输出(并排视图,浏览器打开)
- 差异统计(新增/删除/修改行数)

## 边界
- 只对比文本文件,二进制文件报错
- 大文件(>2MB)先提示,可能很慢
- 不合并、不改动文件

## 执行流程
脚本位于本技能目录 `scripts/diff_tool.py`(标准库,无额外依赖)。

- 文本 diff:`python scripts/diff_tool.py diff 旧.txt 新.txt`
- HTML:`python scripts/diff_tool.py diff 旧.txt 新.txt --html 差异.html`

退出码:0 成功(无差异也返回 0 并说明);1 参数错误;2 处理错误。

## 输出格式
diff 文本按标准格式;HTML 回报路径;末尾给差异统计。

## 示例
输入:「对比下合同改了什么」
动作:diff 旧合同.txt 新合同.txt --html
回报:「共 7 处差异(3 增 2 删 2 改),高亮页见 差异.html。」

## 注意事项
- 编码不一致先统一 UTF-8(见「文件编码转换」)
