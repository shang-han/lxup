# 图片处理

## 定义
对图片文件执行真实操作(转换/压缩/缩放/裁剪/旋转),产出真实图片文件。

## 适用场景
- 图片格式不兼容要转换(png/webp/jpg)
- 图片太大要压缩(传文件、发邮件)
- 缩放尺寸、裁剪、旋转

## 核心能力
- info:尺寸、格式、大小
- convert:格式互转(jpg/png/webp),质量可调
- resize:等比缩放(长边上限)或指定宽高
- crop:按坐标或居中裁剪
- rotate:90/180/270° 无损旋转或任意角度

## 边界
- 只处理图片文件,不做图像内容生成与理解
- 压缩有损是预期行为,重要图片先备份
- 不处理视频与 PDF(见「图片PDF转换」)

## 执行流程
脚本位于本技能目录 `scripts/image_tool.py`,依赖 `pillow>=9.0`(缺失时脚本提示安装命令)。

- 查看:`python scripts/image_tool.py info 图片.png`
- 转换:`python scripts/image_tool.py convert 图片.png -o 图片.jpg --quality 85`
- 缩放:`python scripts/image_tool.py resize 图片.png -o 小图.png --max-side 1280`
- 裁剪:`python scripts/image_tool.py crop 图片.png -o 裁图.png --box 0,0,500,500`
- 旋转:`python scripts/image_tool.py rotate 图片.png -o 旋转.png --angle 90`

退出码:0 成功;1 参数/依赖错误;2 处理错误。

## 输出格式
回报输出路径、新尺寸、文件大小。

## 示例
输入:「这张图太大了,压到 1MB 以内」
动作:先 info 看尺寸,再 convert --quality 压缩
回报:「已压缩为 图片.jpg,1280×960,860KB。」

## 注意事项
- 输出路径不得与源文件相同(脚本自动拦截)
- 依赖缺失时按脚本提示执行 `pip install "pillow>=9.0"`,不要静默失败
