# 目录结构生成

## 定义
把目录层级渲染成 Markdown 树状结构文档,可限制深度与排除目录。

## 适用场景
- README 里放项目结构图
- 项目交接时的目录说明
- 盘点资料目录

## 核心能力
- 树状结构输出(带注释槽位)
- --max-depth 限制层级、--exclude 排除目录
- 只列结构(默认)或带文件大小(--size)

## 边界
- 只生成文本结构,不输出图片树
- 默认排除 .git、node_modules、__pycache__
- 大目录先限制深度,防止输出爆炸

## 执行流程
脚本位于本技能目录 `scripts/tree_tool.py`(标准库,无额外依赖)。

- `python scripts/tree_tool.py tree ./目录 -o 结构.md --max-depth 3 --exclude node_modules .git`

退出码:0 成功;1 参数错误;2 处理错误。

## 输出格式
结构.md:代码块包裹的树状目录;末尾附文件/目录计数。

## 示例
输入:「生成这个项目的目录结构,写到 README 用」
动作:tree --max-depth 2 --exclude node_modules
回报:「已生成 结构.md,3 层结构、42 个目录 138 个文件。」

## 注意事项
- 输出超过 500 行时截断并提示调整深度
