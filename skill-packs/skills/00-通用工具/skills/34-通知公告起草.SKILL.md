# 通知公告起草

## 定义
把要传达的信息写成简洁、层级清晰的通知/公告文本,适配群消息或正式发文两种形态。

## 适用场景
- 行政通知(放假、调休、会议)
- 活动公告(报名、地点变更)
- 群消息(接龙、提醒、值班表)

## 核心能力
- 两种形态:群消息(精简口语)/ 正式公告(标题+正文+落款)
- 关键信息(时间、地点、人物、要求)置顶标粗
- 需要回复/接龙的给出明确指令句

## 模板库
- 放假通知:「【单位】关于【节日】放假安排的通知」:放假时间 → 调休安排 → 值班与联系方式 → 安全提醒
- 会议通知:时间地点(具体到楼层房间)→ 议题 → 参会人 → 需携带材料
- 活动公告:活动主题 → 时间地点 → 报名方式 → 报名截止
- 群接龙/提醒:一句话背景 → 编号接龙格式示例 → 截止时间

## 质量关卡(输出前逐条自查)
1. 5W1H(何时/何地/何事/何人/为何/如何)逐项自查,缺失的向用户确认
2. 时间写具体日期+星期,如「8 月 18 日(周二)」,不用「下周三」这类相对说法
3. 需要收件人行动的,指令句一眼可见(接龙/回复/携带)
4. 落款单位与发文日期未编造

## 边界
- 只传达用户提供的信息,不自行加条件
- 不编造落款单位与日期,缺失留空提示
- 不写带情绪或攻击性的措辞

## 执行流程
1. 确认形态(群消息/正式)与接收对象
2. 提炼关键信息,套对应模板
3. 过质量关卡(重点核对时间地点与用户原话一致)

## 输出格式
标题(正式形态)+ 正文(关键信息加粗)+ 落款(占位)。

## 示例
输入:「周五下午 3 点全体开会,讨论 Q3 计划,在 2 楼会议室,让大家带上材料」
回报:群消息版 + 正式公告版各一份

## 注意事项
- 时间地点等信息必须与用户原话一致
