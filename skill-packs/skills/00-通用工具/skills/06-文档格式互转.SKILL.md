# 文档格式互转

## 定义
把一种常见文本/数据格式无损转换为另一种,输出到目标文件。

## 适用场景
- 配置从 JSON 迁到 YAML(或反向)
- CSV 数据要交给用 JSON 的系统
- Markdown 要发布成 HTML

## 核心能力
- csv ↔ json、json ↔ yaml、md ↔ html、txt ↔ md(文本透传)
- 自动按输入/输出扩展名选择转换路径
- 支持批量(同目录同类型文件)

## 边界
- 只做格式映射,不改数据内容与键名
- csv 首行为表头;无表头的 CSV 先说明再处理
- 不做类型推断:数字/布尔保持字符串形态不变

## 执行流程
脚本位于本技能目录 `scripts/conv_tool.py`,依赖 `yaml`、`markdown`(缺失时脚本提示安装命令)。

- `python scripts/conv_tool.py convert 输入.csv -o 输出.json`
- 批量:`python scripts/conv_tool.py convert ./目录 -o ./输出目录`

支持路径:csv↔json、json↔yaml、md→html、txt→md。退出码:0 成功;1 参数/依赖错误;2 处理错误。

## 输出格式
回报每个文件的 输入格式 → 输出格式 与输出路径。

## 示例
输入:「把 config.json 转成 yaml」
动作:`python scripts/conv_tool.py convert config.json -o config.yaml`
回报:「已转换 config.json → config.yaml(JSON→YAML)。」

## 注意事项
- 不支持的方向脚本会报错并说明,不要自己手写转换假装成功
- 依赖缺失时按脚本提示安装,不要静默失败
