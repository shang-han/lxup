# 表格转换

## 定义
把表格数据在 CSV / Markdown / JSON / HTML(可选 xlsx)之间转换。

## 适用场景
- 表格要贴进聊天或文档(Markdown)
- CSV 要发布成网页表格(HTML)
- xlsx 转 CSV 做数据处理

## 核心能力
- csv ↔ md、csv ↔ json、md → html、json → md
- xlsx → md/csv(需 openpyxl,缺失时提示安装)
- 保持表头与行列顺序

## 边界
- 只做格式转换,不改数据
- 嵌套结构(JSON 多层)只取第一层数组
- 单元格内换行转义为空格,避免破坏格式

## 执行流程
脚本位于本技能目录 `scripts/table_tool.py`(标准库;xlsx 需 openpyxl)。

- `python scripts/table_tool.py convert 输入.csv -o 输出.md`(按扩展名自动判断方向)
- 批量:`python scripts/table_tool.py convert ./目录 -o ./输出目录`

支持方向:csv↔md、csv↔json、md→html、xlsx→md/csv。退出码:0 成功;1 参数/依赖错误;2 处理错误。

## 输出格式
回报每个文件的转换方向与输出路径。

## 示例
输入:「把这个 CSV 转成 Markdown 表格贴给我」
动作:convert 数据.csv -o 表格.md
回报:Markdown 表格(首行表头 + 分隔行 + 数据行)

## 注意事项
- 依赖缺失时按脚本提示安装 openpyxl,不要静默失败
