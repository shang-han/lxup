# 图片防泄密处理

## 定义
查看并清除照片里的 EXIF/元数据(含 GPS 位置),防止发图泄露拍摄地点、设备与时间。

## 适用场景
- 对外发照片前清除位置与设备信息
- 检查收到的图片包含哪些隐私元数据
- 批量清理发布素材

## 核心能力
- info:查看 EXIF(GPS、拍摄时间、设备型号)
- strip:清除全部元数据,输出干净副本
- 批量处理,原图不动

## 边界
- 只处理元数据,不改图片内容本身
- 微信等平台发送时可能自动剥离元数据,但本地文件发送/网盘上传不剥离——先清理再发
- 不处理视频元数据

## 执行流程
脚本位于本技能目录 `scripts/exif_tool.py`,依赖 `pillow>=9.0`(缺失时脚本提示安装命令)。

- 查看:`python scripts/exif_tool.py info 照片.jpg`
- 清除:`python scripts/exif_tool.py strip 照片.jpg -o 干净.jpg`
- 批量:`python scripts/exif_tool.py batch ./照片目录 --outdir ./已清理`

退出码:0 成功;1 参数/依赖错误;2 处理错误。

## 输出格式
- info:列出 GPS/时间/设备字段;无元数据则说明
- strip:回报输出路径;批量回报清理数量

## 示例
输入:「这张照片发出去前帮我清掉位置信息」
动作:info 确认有 GPS → strip
回报:「已清除 GPS、拍摄时间、设备信息,输出 干净.jpg。」

## 注意事项
- 依赖缺失时按脚本提示执行 `pip install "pillow>=9.0"`,不要静默失败
