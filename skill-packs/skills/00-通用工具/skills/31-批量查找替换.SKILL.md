# 批量查找替换

## 定义
在指定目录的文本文件中批量查找并替换指定内容,先预览改动再执行。

## 适用场景
- 一批文档里统一改名称/术语
- 代码里批量替换变量名或路径
- 配置内容批量修订

## 核心能力
- 按扩展名过滤(.md/.txt/.py 等)
- 报告每个文件的替换次数
- --dry-run 只列计划不写入;替换前自动备份

## 边界
- 只处理文本文件,二进制跳过并说明
- 默认大小写敏感;需要忽略大小写用 --ignore-case
- 不跨目录递归时只处理当前目录(--recursive 打开)

## 执行流程
脚本位于本技能目录 `scripts/replace_tool.py`(标准库,无额外依赖)。

- 预览:`python scripts/replace_tool.py replace ./目录 --find "旧词" --replace "新词" --ext .md,.txt --dry-run`
- 执行:`python scripts/replace_tool.py replace ./目录 --find "旧词" --replace "新词" --ext .md --backup`

退出码:0 成功;1 参数错误;2 处理错误。

## 输出格式
dry-run:各文件「N 处」与总数;执行:替换总数、备份位置。

## 示例
输入:「把 docs 目录里的"OpenClaw"统一改成"LXUP"」
动作:dry-run 预览 → 用户确认 → 执行(带备份)
回报:「已替换 5 个文件共 23 处,备份在 .bak 目录。」

## 注意事项
- 正式执行前必须给用户看 dry-run 统计并确认
