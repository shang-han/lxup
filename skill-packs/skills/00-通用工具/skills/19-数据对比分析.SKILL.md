# 数据对比分析

## 定义
以指定键对齐两份结构化数据,输出「新增 / 删除 / 字段变更」三类差异的 Markdown 报告。

## 适用场景
- 新旧两版名单/价目表核对
- 接口返回数据与预期比对
- 迁移前后数据一致性检查

## 核心能力
- CSV/JSON 两种格式
- 按主键对齐;变更字段逐项列出(旧值 → 新值)
- 差异摘要计数

## 边界
- 主键必须唯一;重复键会报错并列出
- 列名/键名不一致时先提示对齐映射,不猜
- 只报告差异,不改动任何文件

## 执行流程
脚本位于本技能目录 `scripts/compare_tool.py`(标准库,无额外依赖)。

- CSV:`python scripts/compare_tool.py csv 旧.csv 新.csv --key 订单号 -o 差异.md`
- JSON:`python scripts/compare_tool.py json 旧.json 新.json --key id -o 差异.md`

退出码:0 成功(含"无差异");1 参数错误;2 处理错误。

## 输出格式
差异.md:摘要(新增 X 条 / 删除 Y 条 / 变更 Z 条)+ 每类明细表。

## 示例
输入:「对比下这两个月的客户名单,谁新增谁流失」
动作:compare csv --key 客户ID
回报:「新增 23 条、流失 9 条、信息变更 4 条,明细见 差异.md。」

## 注意事项
- 两份文件列名不同时先列出来让用户确认映射
