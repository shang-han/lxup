# 甘特图时间线

## 定义
把任务清单(名称、起止日期)渲染成甘特图图片,直观展示排期与并行关系。

## 适用场景
- 项目启动前排期
- 周会/月会展示进度安排
- 里程碑与交付节点可视化

## 核心能力
- 横向任务条,按开始日期定位
- 里程碑用标记点
- 中文任务名正常显示

## 边界
- 只展示用户提供的任务与日期,不替用户排期
- 任务超过 30 条时建议分组或分期输出
- 日期格式必须 YYYY-MM-DD,否则报错

## 执行流程
脚本位于本技能目录 `scripts/gantt_tool.py`,依赖 `matplotlib>=3.5`(缺失时脚本提示安装命令)。

- `python scripts/gantt_tool.py create 排期.png --data tasks.json`

规格(JSON):
```json
{
  "title": "项目排期",
  "tasks": [
    {"name":"需求确认","start":"2026-08-01","end":"2026-08-07"},
    {"name":"里程碑:上线","start":"2026-08-31","milestone":true}
  ]
}
```

退出码:0 成功;1 参数/依赖错误;2 处理错误。

## 输出格式
回报图片路径、任务数、时间跨度。

## 示例
输入:「把这份排期画成甘特图」
动作:整理 tasks.json,运行 create
回报:「已生成 排期.png,8 个任务,时间跨度 8 月 1 日-8 月 31 日。」

## 注意事项
- 任务起止日期冲突(结束早于开始)会被报错并指出哪条
- 依赖缺失时按脚本提示安装,不要静默失败
