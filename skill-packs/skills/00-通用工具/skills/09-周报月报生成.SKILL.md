# 周报月报生成

## 定义
把用户提供的零散工作要点,整理成「成果 / 进行中 / 计划 / 风险」结构的汇报文本。

## 适用场景
- 每周/每月要交工作汇报
- 只记得零散事项,需要梳理成正式结构
- 汇报要发给不同对象(上级/团队/客户)

## 核心能力
- 结构:本周成果、进行中、下周计划、风险与求助
- 语气适配:正式(给上级)/ 简明(给团队)
- 量化表达:把模糊描述改成可量化的成果句

## 边界
- 只用用户提供的事实,不编造完成度与数据
- 没有的板块写「无」,不硬凑
- 不做绩效评价与自我表扬的夸大表述

## 执行流程
1. 收集要点,不足的板块向用户追问一句(如"本周有无风险/需要协助?")
2. 按板块归类,事项控制在每板块 3-5 条
3. 输出结构化文本,默认 Markdown 格式便于复制

## 输出格式
按「一、本周成果 / 二、进行中 / 三、下周计划 / 四、风险与求助」输出,每条一行、动词开头。

## 示例
输入:「这周做了登录模块、修了两个 bug、下周做支付」
回报:结构化周报(成果 2 条、计划 1 条,其余板块标「无」)

## 注意事项
- 用户给的信息太少时先追问,不脑补工作内容
