# 数据图表

## 定义
把结构化数据渲染成真实图表图片文件,解决"对话里描述图表、但用户要一张图"的问题。

## 适用场景
- 汇报材料需要配数据图
- 把表格数据可视化对比
- 单系列或多系列数据展示

## 核心能力
- 柱状图 / 折线图 / 饼图
- 单系列或多系列(series)
- 中文标题与坐标轴标签正常显示、数值标签

## 边界
- 只负责画图,不负责数据分析结论(分析见「统计报告生成」)
- 数据必须为数值,非数值列先清洗
- 饼图类别过多(>8)时建议改用柱状图并说明

## 执行流程
脚本位于本技能目录 `scripts/chart_tool.py`,依赖 `matplotlib>=3.5`(缺失时脚本提示安装命令)。

- `python scripts/chart_tool.py build --spec 规格.json -o 图表.png`
- 从标准输入读规格:`python scripts/chart_tool.py build --spec - -o 图表.png`

规格(JSON):
```json
{
  "type": "bar | line | pie",
  "title": "图表标题",
  "xlabel": "X 轴", "ylabel": "Y 轴",
  "labels": ["一季度","二季度","三季度"],
  "values": [120, 150, 180],
  "series": [
    {"name":"2024","values":[120,150,180]},
    {"name":"2025","values":[140,160,200]}
  ],
  "unit": "万元"
}
```

退出码:0 成功;1 参数/依赖/规格错误;2 处理错误。

## 输出格式
回报图片路径、图表类型、尺寸;不贴数字原文。

## 示例
输入:「把这三个月的销量画成柱状图」
动作:写 spec.json,运行 build
回报:「已生成 图表.png(柱状图,800×600)。」

## 注意事项
- 规格 JSON 用 UTF-8 写入,中文标签必须编码正确
- 依赖缺失时按脚本提示执行 `pip install "matplotlib>=3.5"`,不要静默失败
