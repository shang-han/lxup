# 流程图思维导图

## 定义
按用户描述生成 Mermaid 图代码,并产出一个内嵌渲染器的 HTML 文件,双击即可看图。

## 适用场景
- 业务流程、审批流说明
- 技术架构、调用时序讲解
- 头脑风暴的思维导图整理

## 核心能力
- 类型:flowchart(流程图)、mindmap(思维导图)、sequenceDiagram(时序图)
- 输出 .mmd 源文件 + .html 预览(内嵌 mermaid.js,离线可开)
- 也支持直接把图嵌入 Markdown 文档

## 边界
- 不渲染 PNG(需要 Node 环境),浏览器 HTML 是标准交付物
- 图只表达用户描述的结构,不自行添加环节
- 节点文字保持简洁,过长的描述拆到注释

## 执行流程
脚本位于本技能目录 `scripts/diagram_tool.py`(标准库,无额外依赖)。

- 生成预览:`python scripts/diagram_tool.py render 图.mmd -o 图.html`
- 只出 Mermaid 代码块:`python scripts/diagram_tool.py render 图.mmd -o 图.md`

退出码:0 成功;1 参数错误;2 处理错误。

## 输出格式
回报 .mmd 与 .html 路径;HTML 用浏览器打开即可看图。

## 示例
输入:「画一下订单退款流程」
动作:写 flowchart mmd → render
回报:「已生成 退款流程.mmd 与 退款流程.html,浏览器打开即可查看流程图。」

## 注意事项
- Mermaid 语法版本以 mermaid@10 为准,生成后自查关键词拼写
- 用户环境没有浏览器时只交付 .md 代码块
