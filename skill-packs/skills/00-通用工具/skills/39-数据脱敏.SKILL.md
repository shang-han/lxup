# 数据脱敏

## 定义
把文本中的敏感字段(手机号/身份证/银行卡/邮箱等)替换为打码形式,输出处理后的文件。

## 适用场景
- 日志或数据要发给外部协作方
- 测试环境需要脱敏数据
- 分享材料里有客户联系方式要先处理

## 核心能力
- 手机号:`138****8000`
- 身份证:`110***********1234`
- 银行卡:`6222 **** **** 1234`
- 邮箱:`zh***@example.com`
- 支持按字段选择(--mode)或全部(all)

## 边界
- 按模式匹配处理,不保证识别所有形态(自定义格式先给样例)
- 不做加密/还原,打码不可逆
- 原文件不动,输出为新文件

## 执行流程
脚本位于本技能目录 `scripts/mask_tool.py`(标准库,无额外依赖)。

- 全部打码:`python scripts/mask_tool.py mask 数据.txt -o 脱敏.txt`
- 只打手机号:`python scripts/mask_tool.py mask 数据.csv -o 脱敏.csv --mode phone`
- mode 取值:phone / id / card / email / name / all(可逗号组合)

退出码:0 成功;1 参数错误;2 处理错误。

## 输出格式
回报处理数量(按类型计数)、输出路径。

## 示例
输入:「把这份客户名单的姓名和手机号打码」
动作:mask --mode name,phone
回报:「已脱敏 数据.csv:手机号 132 处、姓名 132 处,输出 脱敏.csv。」

## 注意事项
- 打码后抽查 1-2 条确认没有遗漏
