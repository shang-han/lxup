# 票据信息提取

## 定义
从发票 PDF 或文本中提取关键字段,输出结构化 JSON/CSV,解决手工抄录发票的问题。

## 适用场景
- 报销前批量整理发票信息
- 发票归档需要字段化台账
- 从多张发票快速汇总金额

## 核心能力
- 提取字段:发票号码、开票日期、金额(价税合计)、购买方/销售方名称、税号
- PDF 文本提取(扫描版无文字层时说明需 OCR)
- 批量处理输出 CSV 台账

## 边界
- 只提取文本层存在的字段;扫描版/图片发票无法提取时说明,不编造数字
- 提取结果仅供参考,金额等重要字段提示用户抽验
- 不做发票真伪查验与税务建议

## 执行流程
脚本位于本技能目录 `scripts/invoice_tool.py`,依赖 `pypdf>=3.0`(缺失时脚本提示安装命令)。

- 单张:`python scripts/invoice_tool.py extract 发票.pdf -o 发票.json`
- 批量:`python scripts/invoice_tool.py extract ./发票目录 -o 台账.csv`
- 也接受 txt 输入(已提取文字的票据)

退出码:0 成功;1 参数/依赖错误;2 处理错误(部分文件无文字层)。

## 输出格式
- 单张:JSON 字段清单(发票号码/日期/金额/抬头/税号),缺失字段标 null
- 批量:CSV 台账 + 汇总金额

## 示例
输入:「把这个文件夹里的 5 张发票信息提取出来」
动作:批量 extract → 台账.csv
回报:「已提取 5 张,合计 12,480.00 元,台账保存为 台账.csv。其中 1 张为扫描版无文字层,需 OCR。」

## 注意事项
- 金额字段必须与票面一致,提取后建议抽验 1-2 张
- 依赖缺失时按脚本提示执行 `pip install "pypdf>=3.0"`,不要静默失败
