# 长图拼接

## 定义
把多张图片按顺序拼接成一张图:纵向长图或横向/网格拼图。

## 适用场景
- 多张聊天截图拼成长图
- 操作步骤截图合成一页说明
- 多图对比并排

## 核心能力
- 纵向拼接(默认,宽度取最宽者)
- 横向拼接、网格拼接(指定每行张数)
- 背景色/间隙可调

## 边界
- 只做拼接,不压缩不修改单张内容
- 图片数量过多(>50)或单张过大时先提示可能很慢
- 输出不覆盖任一输入文件

## 执行流程
脚本位于本技能目录 `scripts/concat_tool.py`,依赖 `pillow>=9.0`(缺失时脚本提示安装命令)。

- 纵向:`python scripts/concat_tool.py concat 1.png 2.png 3.png -o 长图.png --direction vertical --gap 8`
- 网格:`python scripts/concat_tool.py grid ./目录 -o 拼图.png --cols 3 --gap 10 --bg white`

退出码:0 成功;1 参数/依赖错误;2 处理错误。

## 输出格式
回报输出路径、拼接方向、最终尺寸与文件大小。

## 示例
输入:「把这几张聊天截图拼成一张长图」
动作:concat --direction vertical
回报:「已生成 长图.png(1080×4200),2.3MB。」

## 注意事项
- 图片顺序即输入顺序,需要特定顺序的按文件名排序后传入
- 依赖缺失时按脚本提示执行 `pip install "pillow>=9.0"`,不要静默失败
