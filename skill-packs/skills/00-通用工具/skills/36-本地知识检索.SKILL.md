# 本地知识检索

## 定义
在用户指定的本地目录内,先定位相关文件,再检索内容,输出「结论 + 文件路径 + 原文摘录」。

## 适用场景
- 资料多,记不清内容在哪个文件
- 需要从本地文档中找到依据
- 跨多个文件找同一主题的内容

## 核心能力
- 文件名/目录名关键字定位
- 内容检索(逐文件关键词匹配,支持 md/txt/docx 等文本文件)
- 输出带路径与摘录,方便用户溯源

## 检索策略(按轮次递进)
1. 文件名命中:关键词 + 常见扩展名过滤,先列出候选文件清单
2. 内容命中:对候选文件全文检索关键词及其近义词
3. 交叉验证:同一主题在多个文件出现时,标注哪个最新/最权威,并说明判断依据
- 支持的检索对象:文本型文件;PDF 扫描件、图片型内容不可检索,如实说明

## 证据标准
- 每条结论必须有「文件路径 + 原文摘录(带上下文 1-2 句)」,无来源不写
- 结论与摘录一一对应,摘录不足以支撑时标注「依据较弱」

## 质量关卡(输出前逐条自查)
1. 已说明检索范围(目录、扫描文件数、关键词)
2. 摘录与原文件内容逐字一致(复制,不转述)
3. 关键词 0 命中时,换同义词再检索一轮,仍无才报「未找到」
4. 未跨出用户指定的目录范围

## 边界
- 检索范围必须在用户给的目录内,不擅自全盘搜索
- 大目录先报告文件量,分轮检索
- 检索不到时如实说明已检索的范围,不编造结果

## 执行流程
1. 确认检索目录与关键词
2. 按三轮策略:文件名 → 内容 → 交叉验证
3. 输出:结论摘要 + 命中文件路径 + 每处摘录

## 输出格式
```
结论:<一句话>
命中文件:
- 路径(命中 N 处)
  - 摘录:……
检索范围:<目录> 共扫描 N 个文件,关键词「……」
```

## 示例
输入:「在 D:\资料 里找关于"报销流程"的内容」
回报:3 个文件命中,每处摘录 + 路径,并总结流程要点

## 注意事项
- 用户目录权限不足时报告无法访问的路径,不静默跳过
