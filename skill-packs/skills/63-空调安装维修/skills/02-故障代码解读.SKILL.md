# 故障代码解读

## 适用场景
客户报修说「空调显示 E1/ flashing 灯」「开了半天不凉」，师傅远程初步判断或上门前准备工具配件，快速锁定故障范围。

## 核心能力
- 按品牌系列（格力/美的/海尔/大金/变频通用）解读常见故障代码含义
- 现象归类：不制冷/不制热、不开机、漏水、异响、跳闸、通讯故障
- 给出从简到繁的排查路径（遥控器设置→滤网→电源→传感器→冷媒→主板）
- 判断用户可自行处理项（滤网脏堵、模式设错）与必须上门项
- 结合代码预估所需配件与工时，辅助接单报价
- 安全类故障（漏电跳闸、R32 泄漏）的应急处置提示

## 常见代码对照表（常见机型整理，最终以该型号服务手册为准）

| 品牌 | 代码 | 常见含义 | 常见原因（按概率） |
| --- | --- | --- | --- |
| 格力 | E1 | 系统高压保护 | 冷凝器脏堵、外机风机不转、冷媒过多或系统堵塞 |
| 格力 | E2 | 室内防冻结保护 | 滤网脏堵风量小、室内机换热不良、缺氟 |
| 格力 | E3 | 系统低压保护 | 冷媒泄漏、蒸发器脏堵、节流装置异常 |
| 格力 | E4 | 压缩机排气高温保护 | 冷媒不足、冷凝不良、排气感温包异常 |
| 格力 | E5 | 过电流/低电压保护 | 供电电压不稳、压机过载、电路异常 |
| 格力 | E6 | 通讯故障 | 内外机连接线接触不良、主板故障 |
| 格力 | H5 | 变频模块保护 | 模块过热、压机异常、电压波动 |
| 美的 | E1 | 室内外机通讯故障 | 连接线松动、主板故障 |
| 美的 | E3 | 室内风机转速异常 | 风机电容失效、电机故障 |
| 美的 | P0 | 变频模块保护 | 模块过热、压机异常 |
| 美的 | P1 | 电压过高/过低保护 | 供电电压波动 |
| 大金 | U4 | 室内外机通讯故障 | 连接线、主板（大金代码多为 U/A/C 系字母组合） |

- 海尔等其余品牌/系列代码差异大：不凭记忆硬套，按「核对铭牌 → 查该型号服务手册」流程执行，查不到时改走现象归类排查。
- 表中「通讯故障」类（格力 E6/美的 E1/大金 U4）占变频机报修大头：先查连接线是否松动、端子是否氧化，再怀疑主板。

## 核对流程
1. 让客户拍铭牌（型号、出厂日期、匹数），确认品牌与系列
2. 按品牌+系列对照代码表或服务手册
3. 代码与机型对不上时，按现象归类排查，不只看代码
4. 远程给方向不给定论，话术留余地（「大概率是…，具体上门测了才知道」）

## 输出格式
1. 【代码/现象含义】对应的故障部件或系统
2. 【常见原因】按概率排序
3. 【排查步骤】逐步操作与仪表
4. 【用户可自查项】让客户先试的简单操作
5. 【上门准备】需带的配件/工具
6. 【安全提示】涉及电/冷媒的风险点

## 示例
输入：「客户说格力空调显示 E1，室内机不制冷」
输出：先请客户拍铭牌确认型号与系列 → E1 多为系统高压保护 → 原因：①外机冷凝器脏堵散热不良 ②外机风扇不转 ③冷媒过多或系统堵塞 ④高压开关故障 → 自查：让客户先看外机有没有转、散热片是不是很脏（脏了清洗可缓解）→ 上门准备：压力表、万用表、清洗设备 → 安全：检测前断电，R32 机型检漏禁用明火。

## 注意事项
- 同一代码不同品牌/年份含义不同，务必让客户拍铭牌确认具体型号
- 高压/低压保护往往是系统问题的表象，别只复位了事，要查根因
- 涉及制冷剂操作提示持证规范作业，R32 泄漏先通风断电
