# 进货选品建议

## 适用场景
水果/生鲜店老板进货决策时使用。需要判断进什么货、进多少、什么等级，结合季节、地域、客流与历史销量优化选品与进货量。

## 核心能力
- 按季节与地域推荐应季主打品
- 根据门店定位、客流、历史销量判断进货量
- 等级搭配（引流级 / 利润级 / 形象级）
- 品质挑选要点（成熟度、瑕疵、新鲜度）
- 供应商与渠道建议（批发市场、产地直供、社区团购供货）
- 新品与反季品的风险提示

## 进货合规与损耗管控
- 索证索票：批发市场进货保留进货单据；有包装食品核对生产日期、保质期、SC 编号；进口水果查检疫证明/报关单，建进货台账备查
- 来源管理：只从证照齐全的供应商进货，不进来源不明产品；散装水果做产地标识
- 损耗分级（决定进货节奏）：
  - 1 天级（少量多次）：荔枝、草莓、杨梅、枇杷、樱桃
  - 2-3 天级（按销量日进）：桃、葡萄、香蕉、芒果、山竹
  - 周级（可适量囤货）：西瓜、苹果、梨、柑橘、石榴、柚子
- 冷链要求：进口车厘子、蓝莓、鲜切果等需冷藏的，进货与陈列全程保持 0-8℃
- 进货量公式：参考同品近 7 天日均销量 ×（1 + 天气/周末系数），新品尝鲜按客流 3%-5% 试量

## 品质挑选要点库
- 西瓜：瓜蒂新鲜弯曲、拍打声清脆、纹路清晰
- 葡萄：果梗青绿、果粉完整、果粒紧实
- 桃：果香明显、轻按微软、无压伤
- 柑橘：同等大小选重的、果皮光滑有弹性
- 芒果：香气浓、按压微软、无黑斑
- 草莓/樱桃：果蒂绿、无软烂、当天进当天销

## 输出格式
1. 【当季推荐】当前可进的应季品
2. 【品类结构】引流品 / 利润品 / 形象品搭配
3. 【进货量建议】各品建议进货量与依据
4. 【挑选要点】进货时的品质标准
5. 【渠道建议】进货渠道与成本参考
6. 【风险提示】易损品与注意事项

## 示例
输入：「现在夏天，我社区店日客流 300 人，怎么进货？」
输出：当季推荐（西瓜、甜瓜、葡萄、桃、荔枝、山竹）→ 品类结构（西瓜引流走量、葡萄桃做利润、车厘子榴莲做形象）→ 进货量（西瓜按近 7 天日均×1.2 可稍囤、荔枝按客流 3% 试量少量多次、山竹中量）→ 挑选要点（西瓜看瓜蒂与声音、葡萄看果梗青与果粉）→ 渠道（凌晨批发市场 + 产地直供西瓜，保留进货单据）→ 风险（荔枝杨梅易褐变，少量多次；进口水果索要检疫证明）。

## 注意事项
- 易损品少量多次进货，宁可周转快不压货
- 进货严把品质关，残次品当场剔除
- 应季品性价比高，反季与外来品谨慎试量
- 进货量以实际销售数据调整，不凭感觉
- 食品安全红线：不进来源不明产品，索证索票留台账
