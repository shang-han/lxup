🦞 龙虾U盘（LXUP）使用说明

多 AI 助手统一平台 · 内置 OpenClaw / Hermes / Codex 三引擎

通用事项看第一部分；三个引擎各自的页面与用法分章写，相同页面会注明「参考 OpenClaw」。

一、产品介绍

龙虾U盘是一个插在 U 盘里、即插即用的 AI 助手平台，一个控制台管三个 AI 引擎：

  • OpenClaw主力引擎：实时聊天、微信/QQ/飞书等渠道、技能生态、多 Agent、人格工作区、定时任务
  • Hermes另一套 Agent 引擎：自带技能市场、记忆三件套（MEMORY/USER/SOUL）
  • CodexOpenAI Codex 命令行引擎：代码向，按需拉起、跑完即退

所有运行环境（Python、Node、引擎本体、内置 Chrome）都打包在文件夹里，不需要在你电脑上安装任何东西。

二、使用前的准备（解压与杀毒）

  1. 不要直接在压缩包里双击运行！必须先完整解压。
  2. 解压到盘根下的短路径，例如 D:\龙虾U盘 或 D:\lxup。
    不要放在桌面、不要套很多层文件夹。Windows 有 260 字符长路径限制，路径太深会让深层文件静默丢失（典型后果：微信二维码出不来）。推荐用 7-Zip 或系统自带解压。
  3. 杀毒软件可能把便携版 Python / Node 误报拦截。若服务起不来，把整个文件夹加入白名单/信任区后重新解压。
  4. 日常打开控制台不联网也行；AI 对话、微信扫码、补装插件、技能市场需要网络。

三、启动：只认 LXUP启动器.exe

  1. 打开文件夹，双击 LXUP启动器.exe —— 这是唯一入口。
  2. 双击后没有窗口、像没反应，是正常的（启动器静默）。后台依次拉起 5 个服务，一般 10~60 秒后浏览器自动打开 http://localhost:5173。
  3. 浏览器没自动打开就手动输入上面的地址。
  4. 浏览器建议：推荐 Edge（Windows 自带）或 Chrome。UC 等国产浏览器要用新版（按 F12 在控制台输入 navigator.userAgent，看 Chrome/ 后面的数字，≥ 93 才行），并且关闭云加速 / 智能转码——这类功能会把本地地址代理到云端，导致聊天连不上网关。
  5. 不要连续反复双击 exe：有单实例锁，重复双击只会退出或只多开一个浏览器页。

LXUP 启动器控制器功能

  • 服务状态：显示 Sidecar（:7889）、OpenClaw（:18789）、Hermes（:8642）、AI Assistant（:8080）和 Frontend（:5173）的运行状态与监听端口。绿色圆点表示“运行中”，灰色圆点表示“已停止”。
  • 启动全部：执行启动前置检查，按顺序启动各项服务并等待端口就绪；服务全部准备好后会自动打开 http://localhost:5173 控制台。
  • 停止全部：停止启动器管理的服务及其子进程。停止其他账户启动的进程时，可能需要管理员权限。
  • 打开控制台：服务启动后，打开本地 LXUP 控制台页面。
  • 检查更新：连接更新服务器检查新版本；发现更新后显示版本和更新内容，并执行相应更新。
  • 运行日志：实时显示服务启动、端口就绪、停止、更新和错误信息；详细服务日志保存在 runtime\logs。
不要从别的地方进：不要手动双击 其他启动脚本，也不要只开页面不启动服务。exe 启动时会给所有服务注入关键环境变量（状态目录、授权服务器、便携 Python）。手动启动会丢变量，导致微信插件、人格文件、会话"串错地方"。

例外：stop-all.bat 用来关机（第六节）；bootstrap-*.bat 只在第七节故障排查提到时才允许运行。

启动自检页（浏览器打开后首先看到）

浏览器自动打开 http://localhost:5173 后，首先进入启动自检页。页面逐项检查运行环境，授权校验通过后自动进入控制台。页面内容与功能：

  • 语言切换：右上角「中文 / EN」按钮，随时切换界面语言。
  • 自检项：「前端模块已就绪」与「授权 · 激活校验」两项，逐项打勾；失败项显示红色叉号并给出原因。
  • 授权校验：经 Sidecar（:7889）检查本机授权状态。
    • 未激活：显示激活码输入框，输入随 U 盘附带的激活码后点「激活」。
    • 离线超过 3 天：显示「联网重新验证」按钮，需联网重新校验。
    • 检测到硬件变更：可重新输入激活码，或点「联网重新验证」。
    • 授权已被吊销：显示「请联系客服」。
    • 校验失败 / Sidecar 不可达：显示「重试」按钮；提示无法连接授权服务时，请先运行 其他启动脚本 再重试。
  • 进度条：显示自检进度百分比；通过后显示「便携环境已就绪」，约 1.2 秒后自动进入控制台。
  • 设备指纹：进度条下方显示本机设备指纹（授权绑定的依据）。
  • 运行日志：底部实时输出自检过程日志，便于排障时把关键行发给提供方。

自检只校验前端模块与授权状态；引擎（OpenClaw / Hermes）未启动不阻塞进入控制台，可在控制台内按需启动。

四、第一次使用：激活

激活现已集成在启动自检页（三之「启动自检页」）中：未激活时自检页直接显示激活码输入框，校验通过后自动进入控制台，无需单独操作。以下仍对激活逻辑做完整说明，便于遇到问题时排查。
  1. 首次打开页面看到激活界面：输入随 U 盘附带的激活码，点「激活」。
  2. 激活与本机硬件绑定；换电脑、或提示「检测到硬件变更」时，重新输码或点「联网重新验证」。
  3. 激活后先做一件事：给你要用的引擎配模型（OpenClaw → 九之 4；Hermes → 十；Codex → 十一之 1）。不配模型 = AI 不回话（提示 No API key）。

六、正常关闭与重启

  1. 右键 stop-all.bat → 「以管理员身份运行」（必须管理员）。
  2. 它按端口精准杀龙虾自己的 5 个服务，不会误杀你电脑上别的程序。
  3. 重启 = stop-all 后重新双击 exe。
  4. 也可以逐个关黑色命令行窗口，或任务管理器结束进程。

七、冲突与故障排查（重点）

故障① 双击 exe 报「端口已被占用 / 另一个实例正在运行」

原因：电脑上还有另一份龙虾在跑（上次没关干净 / 第二份 U 盘副本 / 手动开过 start-all）。

  1. 去另一份龙虾文件夹右键 stop-all.bat 以管理员运行；或直接关掉它的黑色窗口。
  2. 找不到在哪：任务管理器结束所有 node.exe 和 python.exe。
    这也会杀掉你其他 node/python 程序，用前确认没有要紧的在跑。
  3. 精准杀法：
    netstat -ano | findstr :18789
taskkill /PID 查到的数字 /T /F
    把 18789 换成 5173 / 7889 / 8642 / 8080 可查其他端口。
  4. 再双击 exe。

故障② 页面提示 token 不匹配 / 连接失败 / 一直「加载模型中」

原因：18789 被另一份 OpenClaw 占着，页面连到了别人的网关。解决：同故障①杀占用后重启。

故障③ Hermes 页面"看起来正常"但会话、模型对不上

原因：8642 被另一份 Hermes 占用。Hermes 被抢端口时不报错，你会静默连到别人的 Hermes——会话是别人的、改的配置不生效。最隐蔽的一种。解决：同故障①。新版启动器检测到端口占用会直接拒绝启动并报 [FATAL]，看到该报错说明还有实例没关干净。

故障④ 微信二维码出不来

  • 页面会直接给出中文原因，按提示做。
  • 提示「微信插件未安装」= 解压丢了深层文件。能联网时双击一次 bootstrap-openclaw.bat 补装，完成后重启整套。
  • 扫码成功但渠道没上线：按上文提示重启整套。

故障⑤ AI 不回话，提示 No API key / 模型错误

没配模型。OpenClaw 在「模型配置」配（九之 4）；Hermes 在「模型配置」页配（十、总览）；Codex 在 Codex 页配（十一之 1）。三个引擎各配各的。

故障⑥ 浏览器没自动打开

手动访问 http://localhost:5173 即可，属系统关联问题，不影响使用。

八、终极办法与求助

  1. 任何"说不清"的异常：stop-all（管理员）→ 重新双击 exe。
  2. 还不行：重启电脑再双击 exe，能清空一切端口占用。
  3. 仍不行：把文件夹路径、现象、runtime\logs 里最新日志发给提供方。
口诀：解压到盘根、入口只认 exe、关机用 stop-all、一台电脑一份龙虾。

九、页面总览与引擎切换

左上角「引擎」下拉切到 OpenClaw。侧边栏分三组：

分组页面
监控仪表盘 · AI 助手 · 实时聊天
配置模型配置 · Agent 管理 · 浏览器自动化 · 消息渠道
扩展技能 · 定时任务 · 检测与修复

以下子节 1~10 按页面逐个写。Hermes / Codex 章节里相同的页面会直接引用这里。

1. 仪表盘

  • 基础服务卡片：各服务在线状态与存活率；「Control UI」卡片点击直达 OpenClaw 原生面板。
  • Agent 舰队：默认 Agent 与数量；模型池：主模型与备选；渠道商数量。
  • 操作按钮：重启 Gateway、检查更新、创建备份（备份配置，仪表盘显示最近备份）。
  • 授权状态卡：已激活 / 未激活 / 需处理；活动会话、当前可调用技能数、最近日志。

隐藏页：Gateway（不在菜单，入口在本页信息卡片 / 聊天页断线时的「Gateway 设置」按钮）

  • 服务端口：Sidecar 上报的实际端口（端口号由网关启动命令决定，这里只展示）。
  • 谁能访问：「仅本机」最安全；「局域网共享」让同网手机/平板也能连——开启时强烈建议同时配认证。
  • 安全认证：Token 密钥（标准，本地/局域网适用）或密码认证（Tailscale Funnel 等对外暴露场景才需要）。AccessToken 可显示查看；保存会替换网关令牌，已有连接会断开，可能需重启网关。
  • Control UI 访问：允许来源白名单（控制台只能从这些 origin 连接）；设备认证状态展示（关闭属危险态，需改 openclaw.json）。
  • Agent 工具权限：工具访问等级等全局策略。

日常无需进这页；要把 AI 开放给同网其他设备时才用得到。

2. AI 助手

独立于 OpenClaw 网关的小助手（:8080），可对话、可执行本地命令行工具，适合修龙虾自己的问题。

  • 设置里可选模型（直接挑「模型配置」里配好的）、启用工具类别（终端命令/文件操作/网页搜索）、人设、知识库。
  • 内置工具卡：检查配置、诊断 Gateway、检查环境、分析日志、一键修复、反馈 Bug、PR 助手等。
  • 支持粘贴/拖拽截图、日志文本一起问。

3. 实时聊天

  • 顶部模型下拉选模型；输入框 Enter 发送、Shift+Enter 换行；流式输出，工具调用会显示卡片。
  • 左侧菜单按钮展开会话列表（OpenClaw 为主会话）。

工作区面板（右上角「工作区 main」胶囊）

  • 点开胶囊弹出工作区面板：左侧核心文件（AGENTS.md / SOUL.md / TOOLS.md / IDENTITY.md / USER.md / HEARTBEAT.md，缺的可点「添加」）与工作区浏览文件树；右侧预览 / 编辑 / 保存。改 SOUL.md 就是改 AI 的人格。
  • 未保存就切文件/关面板会弹确认；页面万一刷新，未保存草稿自动恢复。

快捷键（⌘ 按钮）与斜杠命令

  • 工作区胶囊右边的 ⌘ 按钮弹出快捷键列表，点哪条执行哪条；输入框手打斜杠回车效果相同。
  • OpenClaw 全量：/new 新建会话 · /reset 重置当前会话 · /stop 停止生成 · /model 切换模型 · /model list 查看可用模型 · /model status 当前模型状态 · /think off|low|medium|high 思考强度。
  • 执行结果或报错直接显示在聊天里。

4. 模型配置

  1. 点红色按钮 「＋ 添加服务商」，弹出对话框（见下图）。
  2. 快捷选择：DeepSeek、OpenAI 官方、Anthropic 官方、火山引擎、阿里云百炼、MiniMax、Ollama(本地) 等，点一下自动填充名称与接口地址；列表外的中转站手动填。
  3. 服务商名称：自定义标识（如 deepseek）。保存后不可修改。
  4. 接口地址：通常以 /v1 结尾，如 https://api.deepseek.com/v1；Ollama 填 http://127.0.0.1:11434。
  5. 密钥 (API Key)：服务商官网申请的密钥；无需认证可留空；保存后打码显示。
  6. 接口类型：即模型服务的请求格式"方言"（URL / 鉴权 / 报文结构）。大多数服务商与中转站都说 OpenAI 方言，选「OpenAI Chat Completions (最常用)」；只有直连 api.anthropic.com 官方选 Anthropic Messages、直连 Google 原生接口选 Google Gemini；本地 Ollama 选 Ollama。选错会直接报错。
  7. 模型列表：第一个是主模型（★），其余备选自动切换；逗号可一次加多个，如 deepseek-chat, deepseek-reasoner。
  8. 点「确认」实时生效，无需重启；网关没启动时先存本地、连上自动同步。
  9. 回到页面：服务商卡片显示「已配置 · N 个模型」，聊天顶部下拉能选到即成功。

服务商卡片还可编辑 / 删除；★ 主模型可改；「备选」用于主模型不可用时自动切换。本页与 Hermes 共用，切到 Hermes 引擎时读写 Hermes 自己的配置（见十、总览），两边互不共用。

5. Agent 管理

创建和管理多个 OpenClaw Agent。每个 Agent 可以有自己的显示名称、模型、工作区和渠道绑定。

创建 Agent

  1. 点击「新建 Agent」。
  2. 填写名称（必填，例如 assistant / coder）、模型（可选）和工作区路径（可选）。
  3. 点击「确认」创建。创建后会出现在 Agent 列表中。

名称与 ID

  • 显示名称：Agent 在列表、详情和删除确认框中显示的名称，可以通过「编辑」修改。
  • Agent ID：后台用于定位 Agent 的稳定标识，供模型配置、文件操作、删除等接口使用；改显示名称不会改变它。

列表操作

  • 详情：进入 Agent 的五个详情页签。
  • 编辑：修改显示名称、模型和工作区路径，保存后立即写入网关。
  • 删除：非 main Agent 可删除。删除时必须二选一：删除配置，保留工作区，或删除配置及工作区文件。
两种删除方式都会删除 Agent 配置和会话记录；第二种还会清理没有被其他 Agent 共用的工作区文件，操作不可撤销。默认 main Agent 不能删除。

Agent 详情中的五个页签

  • 概览：只读显示 Agent ID、工作区路径、主模型和推理级别。
  • 文件：读取该 Agent 工作区的文件列表，显示文件大小和更新时间；存在的文件可以打开编辑并保存。文件名以网关返回的实际列表为准，常见核心文件包括 AGENTS.md、SOUL.md、TOOLS.md、IDENTITY.md、USER.md、HEARTBEAT.md。
  • 渠道：查看该 Agent 已绑定的渠道及运行/配置状态；没有绑定时可跳转到「消息渠道」页。
  • 工具：选择权限模板（完全允许 / 仅安全工具 / 禁用所有），或分别填写显式允许、追加允许、显式禁止列表；点击「保存工具配置」写入该 Agent 的工具策略，禁止列表优先级更高。
  • 技能：查看技能白名单，使用复选框启用或停用当前 Agent 可用的 Skills，状态通过网关实时更新。

6. 浏览器自动化

选择 AI 操作网页时用哪一种 U 盘内置 Chrome。不会调用你本机的 Edge 或 Chrome、不读本机登录状态。

  • 固定复用浏览器（保留登录）：复用同一份浏览器数据目录，适合需要登录、Cookie、连续操作的网站。
  • 干净独立浏览器（独立环境）：另一份隔离数据目录，与固定浏览器互不共享 Cookie / 登录 / 历史。
  • 每份配置显示浏览器路径、数据目录、自动化端口；可「检测」「启动测试」。
  • 切换模式后点「重新应用并重启 Gateway」生效；下方还有 openclaw.json 的 browser 配置段可直接编辑保存。

7. 消息渠道

把 AI 接到微信、QQ、飞书、钉钉、Telegram、Discord、Slack、Teams、Signal、Matrix 等渠道。两个页签：渠道列表（接入）与 Agent 对接（把渠道账号路由绑给哪个 Agent，一个 Agent 可绑多条路由）。

微信接入（最常用）

  1. U 盘已内置 openclaw-weixin 插件，显示「已安装」。
  2. 点「扫码登录」，页面出二维码，手机微信扫码并确认。
  3. 提示「登录成功！凭证已保存」后，重启一次整套（stop-all → exe），微信渠道上线。
  4. 掉线需重新扫码。个人微信接入有风控风险，建议用小号。

其他平台

  • 每个平台有「接入步骤」展开：填 AppID / Secret / Bot Token 等（各平台提示去哪申请），点「校验凭证」「接入并保存」；自动安装失败时给手动命令复制到终端执行。
  • QQ 提示「灵魂不在线」时，用该渠道的完整联通诊断逐项排查。

断连与重连（什么情况会掉、怎么恢复）

自动恢复，不用管：

  • 网络短暂断开 / 抖动：渠道监视器自带退避重试，网络恢复后自动续上。
  • 重启整套 / 重启网关：登录凭证已存盘，启动时自动重连，并从上次消息位置继续，不用重新扫码。

需要你操作（重新扫码）：

  • 微信登录态过期（服务端判定 token 失效）：插件会把该账号自动暂停 1 小时避免无效请求，渠道显示停止/最近错误。恢复办法：消息渠道 → 微信 → 「扫码登录」重新扫码。暂停期内不用反复试，到点或直接重扫即可。
  • 微信账号被风控、手机端退出登录、别处顶号：同上，重新扫码。所以前面建议用小号。

其他渠道（Telegram / QQ 等）：

  • 凭证失效或网络受限时，渠道卡片的「最近错误」会显示原因；改好凭证后重启网关生效（仪表盘 → 重启 Gateway，或 stop-all 后重开）。
  • 任何渠道配置改动后，都需要重启网关才生效。

判断技巧：渠道卡片显示「运行中 ●」= 正常；「已停止」或带红色最近错误 = 需要处理。

8. 技能

  • 我的技能：分「我的岗位技能 / 预装通用工具 / 其他可用」，顶部统计「N 项可用 · N 项待修复 · N 项已停用」。待修复=缺依赖，点「补齐依赖」一键修（需联网）；停用的点击恢复启用。
  • 每个技能有「试一下」：把示例问题预填进聊天页直接体验。
  • 岗位技能包商店：购买（当前为演示模式）→ 自动部署到 OpenClaw 与 Hermes 双引擎工作台；已购包可下载 / 卸载、看技能清单与触发词。
  • 市场（ClawHub）：OpenClaw 官方社区技能市场，英文关键词搜索命中率高；安装即装即用、无需重启；社区技能未经官方审核，看清名称与下载量再装；需联网。

9. 检测与修复

点盾牌「开始检测」，一次性体检：OpenClaw 安装、配置文件、认证令牌、设备密钥、版本状态、Sidecar 服务、网关进程、WebSocket 连接、Agent RPC、Hermes 引擎、AI 助手、授权状态、设备指纹、配置读取。

  • 全过 → 「一切正常」；有失败项会列出。
  • 自动修复：以重启网关等方式修复配对类问题。
  • 高级工具：测试 WebSocket、一键修复配对、网络日志，报障前先把这里的截图发给提供方。

10. 定时任务

让 Agent 按时自动干活。创建任务：名称 + Cron 表达式（5 段「分 时 日 月 周」，如 0 7 * * * 每天 07:00、*/30 * * * * 每 30 分钟）+ 触发时发给 Agent 的消息。可编辑 / 立即运行 / 启用停用 / 删除；任务卡片上显示下次执行时间。

任务只在本引擎内有效：OpenClaw 的任务存在 OpenClaw 自己的库里（Hermes 同理，两不互通）。在聊天里问 Agent「有哪些定时任务」，看到的应与本页一致。

触发行为说明：任务到点后网关会新开一个会话执行并把结果存在该会话里（会话列表可见），不会把消息插进你当前打开的聊天窗口。想看到提醒，到会话列表里找最新的 cron 会话，或把交付目标配置到微信等渠道。

十、总览与相同页面

左上角引擎切到 Hermes Agent。侧边栏：监控（仪表盘 · AI 助手 · 实时聊天）+ 配置（模型配置 · 消息渠道）+ 扩展（技能 · 记忆文件 · 定时任务）。

与 OpenClaw 相同的页面，直接参考前文：AI 助手（OpenClaw 章之 2，完全相同）；实时聊天（OpenClaw 章之 3）同样有工作区面板与 ⌘ 快捷键，差异：工作区是 Hermes 家目录（核心文件 SOUL.md / config.yaml / .env），快捷键列表较短（/new /stop /model /model status，无 /reset /think）；技能（OpenClaw 章之 8）差异：市场换成 Hermes 技能市场（多源聚合、安装前自动安全扫描），启用/停用配置热加载；定时任务（OpenClaw 章之 10）：同一页面两引擎通用，差异只是任务存各引擎自己的库、互不互通；模型配置（OpenClaw 章之 4）：同一页面，操作相同；Hermes 后端只存一套配置（模型名 + Base URL + Key），页面通常只有一个「Hermes」服务商卡片、卡片标题直接显示模型名，保存写 config.yaml、即热加载生效，删除模型即清空 Hermes 配置；消息渠道（OpenClaw 章之 7）：同一页面，Hermes 下显示 Hermes 自己的已启用 / 可用渠道，部分渠道需先装 Hermes 插件（页面给出安装命令），配置与 OpenClaw 互不共用。

1. 仪表盘（服务状态）

  • 状态卡：Gateway 状态（运行中 / 已停止 + 监听端口）；当前模型（模型名 + Key ✓/—，只读；配置在「配置 → 模型配置」页，见总览，对应故障⑤）；版本；API 地址（host:port/v1）；「打开面板」卡点击进实时聊天。
  • 连接目标：默认本地 127.0.0.1:8642，也可自定义网关地址（连别的机器上已有的 Hermes）；「检测环境」「应用」。
  • 快捷操作：打开聊天、Hermes 服务（维护操作，见下）、日志（gateway.log）、ENV（自定义变量高级编辑）。
  • 终端命令速查（可复制）：终端对话、doctor 诊断、查看版本、前台启动/停止 Gateway、打开配置目录。

隐藏页：Hermes 服务（入口：仪表盘快捷操作「Hermes 服务」）

  • 状态卡：安装状态（已安装 / 未安装，未安装需先运行 bootstrap）；运行状态（端口 · PID）；当前模型与 Key 状态；连接目标（本地）。
  • 安装状态卡：版本、安装方式、CLI 路径、主目录；关键配置文件标签：config.yaml / .env。
  • Hermes 配置卡：LLM 服务商、模型、自定义接口地址、API Key；按钮「打开配置」进 config.yaml 编辑页（见下），「打开环境变量」进 ENV 编辑页。
  • 健康检查：平台、版本、PID、API 地址。
  • 维护操作：启动 / 重启 / 停止 Gateway；「打开日志」跳到日志查看页。

隐藏页：Hermes 配置（入口：服务页「打开配置」）

config.yaml 原始编辑器：进入时加载文件原文，可直接修改，保存配置由后端校验 YAML 后写回 config.yaml（保存即热加载生效）；「重新加载」放弃改动重新拉取。YAML 写错会提示校验错误、不会写入。

隐藏页：ENV 编辑（入口：仪表盘快捷操作「ENV」/ 服务页「打开环境变量」）

以键值对添加 / 删除自定义环境变量（如 TAVILY_API_KEY、HTTP_PROXY），下次 Gateway 重启后生效。

模型 / Provider 密钥在「配置 → 模型配置」页里管（写 config.yaml），不放在这里。

日志查看页不在侧边栏：从仪表盘快捷操作「日志」或服务页「打开日志」进入（agent.log 等日志文件列表，支持追踪、搜索、下载、刷新）。

2. 记忆文件

三份 Markdown 组成 Agent 长期上下文，在线编辑、保存后新会话生效：

  • MEMORY（笔记）：事实与备忘，会话间持续累积。
  • USER（用户画像）：你的偏好、身份、背景，每次对话都参考。
  • SOUL（灵魂档案）：人格、价值观、说话风格。

与 OpenClaw 章之 3 工作区面板里的 SOUL.md 是同一份文件，两处都能改。

十一、总览

左上角引擎切到 Codex CLI。侧边栏：AI 助手 · 实时聊天 · Codex CLI · 沙箱配置。

Codex 是命令行工具而非常驻服务——按需运行、任务完成即退出；实时聊天每轮拉起 codex exec --json 子进程。首次使用若提示未安装，按页面提示在项目根运行一次 bootstrap-codex.bat（需联网）。
